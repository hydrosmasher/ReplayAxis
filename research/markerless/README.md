# Two-view markerless analysis

Open [the Jupyter notebook](ReplayAxis_Markerless_TwoView.ipynb) and run the introductory code cells to generate a standalone browser viewer from synthetic motion. The notebook also includes a real-video path for two synchronized, overlapping, calibrated views of the same athlete.

See the [synthetic benchmark](../benchmark/) for supporting reconstruction checks and the [project documentation](../../docs/) for the validation plan.

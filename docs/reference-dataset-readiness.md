# ReplayAxis reference dataset and protocol readiness

19 November 2026 · Research only

This screening applies the [analytical capture envelope](analytical-capture-envelope.md) to the two target endpoints. Documentation was reviewed. Files, licenses for specific intended uses, and trial-level suitability have not been independently verified.

| Candidate | Documented evidence | Readiness for ReplayAxis |
|---|---|---|
| [BioCV dataset](https://researchportal.bath.ac.uk/en/datasets/biocv-motion-capture-dataset/) and [data paper](https://doi.org/10.1038/s41597-024-04077-3) | Fifteen participants performing repeated controlled movements, including running. Nine calibrated HD cameras at 200 Hz, optical marker trajectories, and synchronized force plates. Primary trials combine video and marker data. Secondary markerless trials are video-only. | Best documented knee candidate. Screen primary running trials for clean single-foot strikes, usable views, timing metadata and matched joint-angle definitions. A 5 ms video frame period alone does not prove the provisional 2 ms event-alignment allocation. Quantify frame-to-force mapping and interpolation sensitivity. |
| [SportsPose paper](https://openaccess.thecvf.com/content/CVPR2023W/CVSports/papers/Ingwersen_SportsPose_-_A_Dynamic_3D_Sports_Pose_Dataset_CVPRW_2023_paper.pdf) and [access page](https://christianingwersen.github.io/SportsPose/download.html) | Seven hardware-synchronized calibrated views at 90 Hz, dynamic sport actions, and markerless 3D labels assessed in a separate marker-based comparison. Access requires a license review and request. | Useful for a dynamic-pose robustness comparison. Verify whether force-defined running contacts and independently referenced angles exist in the distributed files before treating it as an endpoint benchmark. |
| [OpenCap force-platform synchronization validation](https://pubmed.ncbi.nlm.nih.gov/41600155/) | An event-based synchronization method compared with a force-platform system synchronized to optical capture. Four 60 Hz smartphone views. | Protocol precedent for evaluating independent temporal alignment. Verify endpoint-specific residuals and avoid inferring subframe accuracy from nominal frame rate. |
| [Eassom et al., tennis ball validation](https://doi.org/10.1177/17543371251381488) | Concurrent commercial ball tracking and Vicon on a tennis court with spatial and temporal alignment. Mean 3D track separation 36.8 mm. Journal states the raw data cannot be shared. | Protocol precedent for phase-resolved position validation. No reusable sample for ReplayAxis was identified here. The reported mean separation cannot establish cricket position accuracy. |
| [Where Is The Ball?](https://openaccess.thecvf.com/content/CVPR2025W/CVSPORTS/papers/Ponglertnapakorn_Where_Is_The_Ball_3D_Ball_Trajectory_Estimation_From_2D_CVPRW_2025_paper.pdf) | Uses a synthetic 3D flight benchmark and a real tennis landing benchmark derived from 2D labeling plus court-plane geometry. | Could exercise geometric modeling or landing detection. A landing point on the court plane does not independently identify the full airborne 3D path. |
| [OpenTTGames](https://lab.osai.ai/) | Single-camera 120 fps table-tennis video with ball-image coordinates and event labels. | Suitable candidate for a 2D detector or event baseline. Does not supply independent 3D flight reference. |
| [Cricket match tracking precedent](https://drpaulfelton.com/wp-content/uploads/2022/08/2019-sanders-factors-affecting-performance-in-elite-finger-spin-bowlers.pdf), §3.4 | International-match trajectories from six high-speed cameras. | Documents capture feasibility in a bounded wicket volume. No downloadable synchronized raw views with an independent volumetric position reference were identified in this pass. |

## Evidence gates

**Running.** Inspect BioCV trial metadata, video timestamps, force-channel sampling and trigger conventions, calibration versions, marker model and missing data rules. Compare the angle at the same force-defined instant using independent marker trajectories. Then report candidate event-timing error and the associated end-to-end angle error separately. Match the task to the dataset's validated speed and capture volume.

**Ball.** Require calibrated raw multiview images and an independent 3D position reference over the same visible pre-bounce intervals. Record synchronization residual, registration residual, reference repeatability, and usable coverage by early, middle and late flight. If the reference uses optical tracking, use independently calibrated observations and check targets. Synthetic benchmarks can bound modeling sensitivity. A collection protocol or a downstream landing metric cannot establish real airborne 3D accuracy.

**Decision.** Prioritize BioCV for a controlled knee feasibility benchmark. The fast-ball measurement remains conditionally feasible from the published protocols, with a reusable independent cricket reference still missing from this scan. Avoid setting procurement targets from these candidates alone.

**Next research pass.** Audit BioCV file manifests and timing semantics and expand the ball dataset search to high-speed stereo and independent optical reference collections. Compare access, data coverage and licensing before any analysis or hardware work.

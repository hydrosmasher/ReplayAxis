# ReplayAxis supervisor scope decision

20 November 2026 · Proposed scope for discussion · Decision pending

## Recommended scope

**Primary contribution:** Validate a single markerless running measurement against an independent reference. **Secondary contribution:** Test whether an independent reviewer can reproduce a selected measurement from the exported evidence.

**Research question:** In controlled straight running, how closely does a calibrated multicamera workflow agree with an anatomical reference for sagittal knee flexion at force-defined initial contact, and how many eligible contacts yield a usable angle?

Use **mean absolute angle error in degrees at matched contact times** as the proposed primary outcome. Report bias, uncertainty accounting for repeated contacts from the same athlete, and coverage out of all reference-eligible contacts. Own-event detection is a separate extension. The initial population is runners in the eligible BioCV primary trials, with actual speeds, strike patterns and sample size to be verified. The proposed coaching context is comparing knee flexion before and after a technique cue. The thesis would validate the measurement in the documented conditions. Evaluating an actual cue intervention would require its own design.

## Evidence and fallback

| Decision point | Proposed approach |
|---|---|
| Independent comparison | Use force-defined contact time and marker-derived knee angle with matched side, sign and anatomical convention. Freeze processing and error/coverage criteria before held-out evaluation. [Endpoint protocol](endpoint-validation-protocols.md) |
| BioCV readiness | Proceed with endpoint validation only if authorized access, sufficient eligible contacts and video-to-reference timing can be documented and meet a justified reference budget. Quantify timing sensitivity by documented alignment category. [Dataset audit](biocv-timing-and-ball-data-audit.md) |
| If reference timing cannot be qualified | Seek an alternative synchronized reference. If unavailable within thesis scope, consider a reproducibility-first thesis with a bounded timing sensitivity analysis and clearly exploratory real-data results, subject to supervisor approval. |
| Reproducibility demonstration | Give a reviewer camera/frame IDs, observations, calibration, coordinate conventions, settings, software version and view decisions. Regenerate the selected result and compare to a fixed numerical tolerance. Record whether an existing workflow exposes equivalent evidence. |
| Scope boundary | Keep cricket as a separate transfer question until an independent 3D reference is identified. Use desktop evidence review to illustrate the workflow. Keep an XR/voice/gesture user study, forecasting, and hardware procurement outside the proposed primary evaluation. |

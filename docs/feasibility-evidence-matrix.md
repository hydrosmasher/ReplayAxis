# ReplayAxis evidence extraction — first full-text pass

19 November 2026 · Research only

**Question.** What work already demonstrates the individual capabilities, and what evidence is needed to justify a later trial? This targeted pass extends the prior-work brief. Public text and abstracts were reviewed as indicated. It is not an exhaustive database review or a budget request.

## What this supports

- **Body metric.** Start the research case with sagittal knee flexion during one defined running phase. Use a matched anatomical definition and specify whether the endpoint is a waveform, peak value or angle at an independently identified event. A waveform result and a discrete-event result answer different questions.
- **Fast-object metric.** Use ball center position over the visible pre-bounce interval as the primary outcome. Compare the fitted trajectory with an independently calibrated reference in the same space and clock. Derive speed only after quantifying how filtering and timing affect it. Report spatial error by flight phase plus the proportion of positions withheld.
- **Spatial review.** Literature supports walking around a reconstructed sports event and querying it in XR. The measurement workflow should be judged on whether a reviewer can identify and reproduce a specific result from its original evidence. The cited demonstrations do not establish that complete workflow.
- **Budget gate.** Literature supports a conditional feasibility argument, but numerical requirements depend on the intended coaching decision. Before procurement, specify acceptable position or angle error, event timing error, and minimum coverage for those two metrics. Then model whether capture geometry, synchronization and reference uncertainty can satisfy the bounds. This pass sets no purchasing thresholds.

## Next research step

Expand the citation trail for cricket and tennis ball validation, repeatability of sagittal knee flexion in fast running, and uncertainty in calibration and timing. Extract independent reference uncertainty and error by motion phase wherever available. Use those results to build the pre-hardware error budget. Broader database and patent screening remain separate research work.
